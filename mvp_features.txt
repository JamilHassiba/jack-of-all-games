Included in this file are the features which will be implemented for our MVP, presented in Week 2 Labs.

Features
- Login Page
  This will look like a login page, but without the extras like "forgot pwd"
  This will not be connected to a database
  Any details entered will redirect user to landing page to host room, etc

- Landing Page
  This will have buttons to host, join room - no "rooms" yet this just takes you to the client page
  There will be a scoreboard button but no functionality yet

- Client Page
  This will have renders of cards to show proof of concepts, rather than much gameplay

- Javascript
  Javascript code to call backend api to show proof of concept of dynamic page updating
